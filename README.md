# Pip's Sky Run

A 3D side-scrolling platformer for Chrome, built with three.js. Three worlds, renders at native resolution (4K on 4K screens).

**Play:** open `index.html` in Chrome. It is fully self-contained and works offline.
Add `?low` to the URL (`index.html?low`) for a lighter mode on weak hardware.

**Controls:** ← → move · Space jump (hold for higher) · Shift run · P pause · M music · F fullscreen. On-screen buttons on touch devices.

**Develop:** edit `src/main.js` / `src/index.template.html`, then `npm install && npm run build` to regenerate `index.html`.
